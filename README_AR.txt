منصة تقييم جودة الخدمات - النسخة المتصلة بالإنترنت
====================================================

هذه النسخة جاهزة للربط بقاعدة بيانات Supabase.

ما الذي تفعله؟
1. المرتفق يدخل من الهاتف.
2. يختار الشعبة.
3. يقيم الرضا وجودة الخدمة والاستقبال ووضوح المعلومات وسرعة المعالجة.
4. يحدد تقييم أجل الاستجابة وهل تمت معالجة الطلب.
5. يضيف ملاحظة اختيارية.
6. يتم إرسال البيانات إلى قاعدة البيانات.
7. المسؤول يدخل من dashboard.html بحسابه.
8. تظهر له الإحصائيات والتقييمات حسب الفترة والشعبة.
9. يستطيع تصدير البيانات CSV.

خطوات التشغيل:
----------------
أ) أنشئ مشروعًا مجانيًا في Supabase.
ب) افتح SQL Editor والصق محتوى database.sql ثم نفذه.
ج) أنشئ مستخدمًا للمسؤول من Authentication > Users.
د) انسخ Project URL و anon public key من Project Settings > API.
هـ) ضع القيمتين في config.js:
   SUPABASE_URL
   SUPABASE_ANON_KEY
و) ارفع الملفات إلى استضافة ثابتة مثل GitHub Pages.

تنبيه أمني:
------------
لا تضع service_role key في config.js أو في أي ملف يصل إلى المتصفح.
استعمل anon public key فقط، واترك قراءة النتائج محمية بسياسة authenticated.

QR:
---
يمكن لاحقًا إنشاء QR عام للرابط الرئيسي، أو رابط مخصص لكل شعبة مثل:
?department=الأرشيف
?department=التنفيذ%20المدني
بحيث يفتح الاستبيان مباشرة على الشعبة المطلوبة.

التخصيص:
---------
يمكن إضافة شعار المحكمة، اسم كل شعبة، تقارير PDF، مؤشرات شهرية، مقارنة بين الأشهر، ونظام صلاحيات متعدد المسؤولين.
